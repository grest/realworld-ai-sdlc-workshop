# Allow a user to correct a recently published comment

## User story

As a registered article reader, I want to correct my own comment shortly after publishing it so that obvious typing mistakes do not remain visible.

## Initial acceptance notes

- The user can submit corrected comment text.
- The corrected text is returned by the API.
- Users must not change comments written by someone else.
- Existing comment creation, listing and deletion must continue to work.

## Out-of-scope notes

Not yet agreed. The team should identify likely exclusions during refinement.

## Product note

This item intentionally contains only the initial business request. Missing boundary cases and technical decisions must be surfaced rather than invented.
