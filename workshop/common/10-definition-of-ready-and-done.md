# Definition of Ready i Definition of Done dla pracy z AI

## Definition of Ready

Zmiana jest gotowa do planowania/implementacji, gdy:

- [ ] problem, owner i wartość są znane;
- [ ] źródła i ich status są zarejestrowane;
- [ ] blokujące konflikty mają decyzję;
- [ ] scope jest mały i out of scope jawny;
- [ ] istnieje właściwy context pack;
- [ ] security/architecture constraints są znane;
- [ ] wiadomo, jak sprawdzić rezultat;
- [ ] wymagane approval gates są wskazane.

## Definition of Done

Zmiana jest zakończona, gdy:

- [ ] proposal/specs/design/tasks są zatwierdzone i aktualne;
- [ ] implementacja jest zgodna z scenarios;
- [ ] focused i pełne testy zostały wykonane;
- [ ] diff został manualnie reviewed;
- [ ] `/opsx:verify` został uruchomiony i triaged;
- [ ] security, boundary i negative cases mają evidence;
- [ ] dokumentacja i traceability są aktualne;
- [ ] deviations i remaining risks są jawne;
- [ ] niezależny reviewer podjął decyzję;
- [ ] merge/deployment pozostaje osobną uprawnioną decyzją.
