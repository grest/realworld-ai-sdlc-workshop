# Support case — typo in a published comment

## Summary

A registered user reported a visible spelling mistake in a comment posted under an article. The only available workaround was deleting the comment and creating it again.

## Customer impact

- The replacement comment appeared later in the discussion.
- The user had to recreate the full text.
- The user asked whether a correction could be made without deleting the comment.

## Questions raised by support

- Should a corrected comment be marked as edited?
- Should previous versions be visible?
- How long after publication should correction remain possible?

These questions were forwarded to Product. They are questions and suggestions, not approved requirements.
