# Mapa warsztatu

## Dzień 1

1. Claude Code jako agent w repozytorium.
2. Bezpieczeństwo, permissions i human approval.
3. Markdown jako warstwa wiedzy.
4. **LAB 1:** dokumenty źródłowe → reviewed context pack.
5. Kontrakt zadania, context engineering i stop conditions.
6. Spec-Driven Development i OpenSpec.
7. **LAB 2:** explore → proposal.

## Dzień 2

1. Readiness gate i review artefaktów.
2. **LAB 3:** specs → design → tasks → planning approval.
3. Controlled implementation.
4. **LAB 4:** apply → kod → testy → evidence.
5. Verify i adversarial review.
6. **LAB 5:** cross-review → poprawa → PR.
7. Dokumentacja, sync/archive i model pracy zespołu.

## Jeden wspólny ślad

Każdy LAB rozwija wynik poprzedniego. Nie są to niezależne ćwiczenia.

```text
BRD/backlog/architecture
  -> reviewed Markdown
  -> open questions and decisions
  -> proposal
  -> requirements and scenarios
  -> design and tasks
  -> implementation and tests
  -> verify and review findings
  -> PR description
```
