# Laboratory sequence

| Lab | Main transition | Participant result |
|---|---|---|
| LAB 1 | source documents -> reviewed Markdown | context pack, source register, open questions |
| LAB 2 | reviewed context -> agreed intent | OpenSpec `proposal.md` |
| LAB 3 | intent -> executable plan | delta specs, `design.md`, `tasks.md`, traceability |
| LAB 4 | approved plan -> implementation evidence | code, tests, task progress, evidence log |
| LAB 5 | implementation -> independent decision | verify report, review findings, corrected change, PR description |

Some decisions are intentionally released only during a lab. Do not search other branches, Git objects or external trainer material for unreleased answers.
